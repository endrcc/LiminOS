# liminOS

a dreamcore liminal inspired webOS, 
has a windows 98 vibe heavily inspired by the dreamcore aesthetic, was really fun to make hope yall like this.

## how to open

just open index.html in chrome or firefox.
click or press enter if you wanna skip the boot.

## whats in this version

- wallpaper shows the whole image (no weird cropping)
- colors are muted dusk lavenders / foggy pastels
- app icons are rounded with soft glow
- desktop has blinking eyes, eye-flowers and drifting bird shapes
- boot sequence and shutdown are a bit colder / more threshold feeling
- terminal is called threshold://
- memories gallery scrolls and maximizes properly
- extra grain, vignette and small interactions
