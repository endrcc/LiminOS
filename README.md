# liminOS

a dreamcore liminal inspired webOS, 
has a windows 98 vibe heavily inspired by the dreamcore aesthetic, was really fun to make hope yall like this.

## how to open

just open index.html in chrome or firefox.
click or press enter if you wanna skip the boot.
